# Reports

**Historical audit trail — not default reading.** Work reports live here, one file per
report, named `<YYYY-MM-DD>-<topic>.md`, newest first. They record how the project got to
its current state.

- For the current state, read **[`../PROJECT_STATUS.md`](../PROJECT_STATUS.md)** instead.
- Open a report only to trace a decision or fact back to its evidence.
- Reports are append-only: do not rewrite past reports to match later findings; add a new
  report (or correct the relevant reference) and note the change.
