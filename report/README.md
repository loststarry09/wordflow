# Reports

**Historical narrative — not default reading.** Reports are named `<YYYY-MM-DD>-<topic>.md`
and record how the project reached its current state.

- For the current state, read **[`../PROJECT_STATUS.md`](../PROJECT_STATUS.md)** instead.
- Open a report only to trace a decision or fact back to its evidence.
- The dated per-ticket reports were folded into
  [`v0.1-development-summary.md`](./v0.1-development-summary.md) at the v0.1.0 freeze and
  deleted; Git history is the archive. Reports are not rewritten to match later findings —
  a correction is a new note or an update to the relevant reference.
