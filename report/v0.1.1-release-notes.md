# WordFlow v0.1.1

这是 **correctness / hardening release，无新增 feature**。保留 v0.1 的功能范围与布局 contract，原有 `v0.1.0` tag 不修改、不移动。

## 修复

- **Source / output / report alias protection**：所有相关写入端共用文件身份保护，写入前拒绝直接路径、symlink、hardlink 和父目录 alias；QA 同时核对实际交付文件、plan 和显式 source 的身份。
- **Table portability read-back validation**：拒绝 mismatch / ragged 数据；构建后读取真实 outer / nested table，严格验证 `tblW == ΣcolWidths`。定位真正新建的表，避免旧表掩盖错误；实际不满足时不输出成功或虚假的 change report。
- **Standard-style idempotency**：已有 standard styleId 更新属性，缺少时才 add；对自身输出再次运行成功，不重复 styleId。
- **Cross-reference field isolation**：只清理本轮新建 REF 的 `w:dirty`，保留其他 field 的 dirty、lock 和缓存。
- **QA limited-construct completeness**：覆盖当前全部 limited constructs，包括多栏、页码重启、PAGEREF、复杂公式及各层不满足 portable 条件的 nested table。
- **Real preview artifact validation**：acceptance 逐个验证 preview artifact 是实际存在的非空文件，拒绝只有 metadata 的成功声明。
- **Required Word / WPS / LibreOffice compatibility gate**：每个请求应用都必须真实 repair-free；unavailable、缺记录或 timeout 均 fail。发布验证使用 required 模式，**0 skip**。
- **Process ownership / cleanup safety**：移除 baseline 后新增 PID 的批量清理；仅清理本轮拥有的进程，核对 PID、creation time、image 和 driver command line，并终止固定的 process handle。无关 Word / WPS / PowerShell 保持存活；原生驱动使用隐藏 PowerShell 窗口。
- **TOC concurrency fix**：每次 TOC 测试使用唯一 staging 和 artifact 目录，退出时只清理自身目录；真实并发回归通过。
- **Nested-table fixture invariant correction**：外层 width 从 6803 dxa 校正为 grid sum 6804 dxa，generator / manifest / invariant tests 同步；两层均遵循严格 portable invariant。
