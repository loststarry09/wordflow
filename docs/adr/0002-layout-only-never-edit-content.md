# WordFlow lays out; it never writes or edits content

WordFlow owns layout and only layout. It does not author, rewrite, shorten, translate, or correct a document's words, images, tables, or equations — restyling leaves every element's content untouched. Restructuring (heading levels, section order, grouping of paragraphs) is allowed only on the user's explicit request and per-item confirmation. Rejected: an "AI editor" that also improves the prose — it makes decisions the user did not ask for and makes the result impossible to reproduce.
